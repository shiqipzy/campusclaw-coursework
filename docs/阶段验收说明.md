# 个人项目阶段性验收

本次在原有 CampusClaw 上继续实现第5课的提示词、技能与流式会话，以及第6课的MCP接入。报告先介绍项目及功能，再按作业原顺序分别回答五个验证问题。每节将实现说明、实际请求与返回、相关截图放在一起，共8页、8张图。

本次补充取证保存在 [report/evidence.json](evidence/report/evidence.json)，包括模板配置、上传技能、首轮与最终LLM请求、模型返回、知识库来源、技能停用对照和调用记录；[图片索引](evidence/report/figure-index.json)列出8张实际截图。原接口、参数上限及调用记录等验证结果保存在 [acceptance-summary.json](evidence/acceptance-summary.json)。这些记录使用本项目测试材料，不包含鉴权密钥。

权限检查使用A、B班教师和学生账号分别进行，检查班级资源、会话归属、工具配置及调用记录范围，属于个人项目的测试内容。26个接口脚本均已通过，并与数据库记录核对。报告保留了实际运行结果，也说明了词面检索、关键词技能路由和输出约束的局限。
