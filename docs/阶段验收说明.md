# 个人项目阶段性验收

本次在原有 CampusClaw 上继续实现第5课的提示词、技能与流式会话，以及第6课的MCP接入。正文采用连续的实现说明，结合函数、接口和运行结果回答作业中的五个验证问题。

- [PDF报告](CampusClaw阶段性验收报告.pdf)
- [可编辑正文](个人项目阶段性验收报告.md)
- [项目仓库](https://github.com/shiqipzy/campusclaw-coursework)

模型请求和返回保存在 [llm-exchanges.json](evidence/llm-exchanges.json)，包括系统提示、知识库切片、候选工具、模型工具选择和最终SSE帧。接口、参数上限及调用记录等验证结果保存在 [acceptance-summary.json](evidence/acceptance-summary.json)。这些记录中的内容为本项目测试材料，不包含鉴权密钥。

权限检查使用A、B班教师和学生账号分别进行，检查班级资源、会话归属、工具配置及调用记录范围，属于个人项目的测试内容。26个接口脚本均已通过，并与数据库记录核对。报告保留了实际运行结果，也说明了词面检索、关键词技能路由和输出约束的局限。
