## Context

现有系统为 Go + MySQL + Nginx，具有 JWT、班级材料及 ngram 检索。以第5/6课公开教程和阶段验收截图为需求来源，使用同一 Git 仓库增量实现。

## Decisions

1. 一个班级可有多个 `tutor_agents`，角色提示词放智能体上。会话锁定 agent_id，绑定关系和技能开关每轮重读。
2. 技能采用课程中文元数据格式，不是可执行脚本或 Agent Skills 标准目录。解析后保留源文本；从绑定且启用集合按词命中计分，最多一项，同分取小 ID。
3. 当前问题前置检索本班且绑定的材料，最多4片、每片800字；选中技能的资料范围再筛标题。最近6条历史各500字。
4. 角色提示词和技能说明进 system，资料进 user，工具结果进 tool。无材料也请求真实模型，流式过滤无效引用编号。
5. MCP 教学子集使用 POST /mcp JSON-RPC 2.0，不宣称完整实现所有 MCP 传输与能力。两工具为 formula_hint 和 unit_convert。输入结构用 JSON Schema 验证器编译与执行，不接受外部 schema URL。
6. 技能决定候选工具上限，模型负责选择。宿主每次执行前重查连接与发现清单，并校验同一 schema；工具返回先整条过滤指令式句式，再按2000字截断，以数据角色回传。
7. 工具决策请求 stream=false；决定停止调用后以 stream=true 请求最终正文。默认4轮、每会话累计12条可归属调用上限。验收栈缩为1轮、2条以观察终止。用尽后去掉 tools，基于已有信息回答。
8. 服务端 AES-GCM 加密 MCP 令牌，密钥由 JWT_SECRET 派生；更换 JWT_SECRET 后须重新登记令牌。URL 只能使用服务端允许的主机，禁转发重定向。模型永不接触 MCP 地址和令牌。
9. 调用记录追加写，范围取服务端身份；删除/改名服务器无法归属的新事件仅进入 SSE，历史记录保留。LLM 请求和实际 JSON/SSE 帧另存，仅会话本人可读，绝不记录 Authorization。
10. 接口元数据 `apiOperation` 是 Go 中的可执行文档注解，运行时生成 OpenAPI；Swagger 静态资源随仓库提供，无需运行时访问 CDN。

## Risks / Trade-offs

- ngram 全文检索不等同于向量或混合检索，同义改写召回有限；保留已完成的第四课检索路线。
- 引导式回答主要由提示词约束，真实测试通过不等于对所有题目都能保证不给答案。
- 工具返回句式检查不完备，真正限制动作的是候选集、参数校验及配额。示例仅提供无外部副作用的读/计算工具。
- LLM 请求详情含问题与片段，应按本人权限保护；不记录密钥也不意味着可以公开所有用户对话。
- 真人同伴复核需要第二名实际操作者，自动换账号验证不能代替。
